FurnaceSpawner — Fabric-мод для Minecraft 1.21.4 (только клиент)

Функции:
- Клавиша Y открывает меню выбора моба: панда, шалкер, магма-куб, крипер, чешуйница, ифрит.
- Выбор сохраняется в config/panda-furnace.json.
- Печка визуально заменяется клеткой спавнера с выбранным мобом внутри.
- Настоящий блок остаётся печкой: инвентарь и плавка работают как обычно.
- Серверу мод не нужен.

Как получить .jar (самый простой способ, без установки чего-либо):
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Вкладка Actions -> build -> когда сборка закончится, скачайте артефакт furnacespawner-jar.

Сборка на своём ПК:
1. Установите JDK 21 и Gradle 8.11 или новее (Loom 1.9 не работает с Gradle 8.10).
2. Запустите build.bat (Windows) или build.sh (Linux/macOS) либо `gradle build`.
3. Готовый файл: build/libs/furnacespawner-1.0.0.jar
   (furnacespawner-1.0.0-sources.jar класть в mods НЕ нужно).
4. Положите jar в .minecraft/mods вместе с Fabric Loader 0.16+ и Fabric API для 1.21.4.
